Pendahuluan

Apa Itu Kabel LAN / Ethernet?

Kabel LAN (Local Area Network) atau sering disebut kabel Ethernet/UTP adalah media transmisi fisik berbentuk kabel yang digunakan untuk menghubungkan berbagai perangkat komputasi (seperti Komputer, Laptop, Router, Switch, dan Server) dalam satu area cakupan terbatas.

Fungsi utamanya adalah mentransmisikan sinyal data berupa gelombang elektronik antar perangkat dengan kecepatan tinggi, latensi rendah, serta kestabilan koneksi yang jauh lebih andal dibandingkan jaringan nirkabel (Wi-Fi).

Jenis Kategori Kabel (Cat)

  • Cat 5e: Standar hingga 1 Gbps (100 MHz), ideal untuk rumahan.
  • Cat 6: Kecepatan hingga 10 Gbps pada jarak pendek (250 MHz).
  • Cat 6a / Cat 7: Shielding ekstra untuk industri & server data center.

Dua Konfigurasi Utama Kabel UTP

Straight-Through Cable

Digunakan untuk menghubungkan 2 perangkat yang BERBEDA jenis.

Contoh: Laptop ke Switch / Router

Crossover Cable

Digunakan untuk menghubungkan 2 perangkat yang SAMA jenis secara langsung.

Contoh: Laptop langsung ke Laptop (Peer-to-Peer)
Peralatan Praktikum

Alat & Bahan Crimping Kabel LAN

Peralatan standar yang wajib disiapkan sebelum merakit kabel UTP Ethernet.

1. Kabel UTP (Unshielded Twisted Pair)

Kabel inti berisikan 8 helai kawat tembaga berpasangan yang terpilin. Berfungsi membawa sinyal transmisi data.

2. Konektor RJ-45

Konektor plastik transparan tempat memasukkan 8 pin urutan kabel UTP yang akan ditancapkan pada port LAN laptop/computer.

3. Tang Crimp (Crimping Tool)

Tang khusus untuk mengunci pin tembaga konektor RJ-45 ke helai kabel UTP serta memotong kawat kabel secara rata.

4. Cable Stripper / Pemotong

Alat pengupas jaket/kulit luar kabel UTP agar tidak merusak kawat tembaga bagian dalam saat dikupas.

5. LAN Tester (Cable Tester)

Alat penguji berupa indikator lampu LED (1-8) untuk memastikan seluruh pin kabel sudah terhubung sempurna tanpa putus.

Cara Pembuatan Kabel LAN (Straight & Cross)

Standar T568A Pin Standard A

  1. 1. Putih Hijau
  2. 2. Hijau
  3. 3. Putih Orange
  4. 4. Biru
  5. 5. Putih Biru
  6. 6. Orange
  7. 7. Putih Cokelat
  8. 8. Cokelat

Standar T568B Pin Standard B

  1. 1. Putih Orange
  2. 2. Orange
  3. 3. Putih Hijau
  4. 4. Biru
  5. 5. Putih Biru
  6. 6. Hijau
  7. 7. Putih Cokelat
  8. 8. Cokelat

Catatan Tipe Kabel:

  • Kabel Straight: Ujung 1 = T568B dan Ujung 2 = T568B
  • Kabel Crossover: Ujung 1 = T568B dan Ujung 2 = T568A

Langkah-Langkah Crimping:

Langkah 1

Kupas jaket luar kabel UTP sekitar 2 cm menggunakan Cable Stripper.

Langkah 2

Uraikan 8 pilinan kabel dan urutkan warnanya sesuai standar (Straight/Cross).

Langkah 3

Ratakan pemotongan ujung kawat menggunakan pemotong pada Tang Crimp.

Langkah 4

Masukkan kawat ke RJ-45, lalu tekan (crimp) tang hingga berbunyi 'klik' dan terkunci.

Konfigurasi Jaringan P2P

Cara Menghubungkan 2 Laptop & Setting IP Address

1. Sambungkan Fisik Kabel LAN

Colokkan salah satu ujung konektor RJ-45 kabel LAN tipe Crossover (atau Straight jika laptop modern mendukung Auto-MDIX) ke port Ethernet Laptop A dan ujung lainnya ke Laptop B.

2. Setting IP Address Static pada Windows

Lakukan langkah berikut pada kedua laptop:

  1. Buka Control Panel > Network and Internet > Network and Sharing Center.
  2. Klik menu Change adapter settings di panel kiri.
  3. Klik kanan pada adapter Ethernet, pilih Properties.
  4. Pilih Internet Protocol Version 4 (TCP/IPv4), lalu klik tombol Properties.
  5. Pilih radio button Use the following IP address dan isi nilai berikut:
Perangkat IP Address Subnet Mask
Laptop A (Utama) 192.168.1.1 255.255.255.0
Laptop B (Tujuan) 192.168.1.2 255.255.255.0

Pengecekan Keterhubungan (Ping Test)

Langkah pengujian komunikasi data antar dua laptop menggunakan protokol ICMP melalui utilitas Command Prompt (CMD).

Keterangan Sukses (Reply From)

Menandakan kedua laptop telah terhubung sempurna tanpa ada paket data yang hilang (0% loss rate).

Jika Error (Request Timed Out)

Pastikan Windows Firewall pada kedua laptop dimatikan sementara dan IP Address sudah berada di subnet yang sama.

Sharing Data

Cara Transfer File Antar Laptop

1

Aktifkan Network Sharing

Buka Control Panel > Network and Sharing Center > Advanced sharing settings. Aktifkan opsi Turn on network discovery dan Turn on file and printer sharing. Matikan opsi Password protected sharing agar akses lebih instan.

2

Share Folder Tujuan

Klik kanan pada Folder yang ingin dibagikan > Properties > Tab Sharing > Klik Advanced Sharing. Centang Share this folder, lalu pada tombol Permissions beri akses Full Control untuk Everyone.

3

Akses File dari Laptop B

Di Laptop B, tekan kombinasi tombol Win + R untuk membuka RUN. Ketik \\192.168.1.1 dan tekan Enter. Folder terpilih siap disalin!
